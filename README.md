# #100DaysOfCode

My ongoing **#100DaysOfCode** journey — building projects, sharpening skills, and documenting progress one day at a time.

Inspired by the [100 Days of Code](https://www.100daysofcode.com/) challenge created by [Alexander Kallaway](https://github.com/kallaway/100-days-of-code).

## About the Challenge

The goal is simple: **write code every day for 100 days.**

This repository documents my progress through multiple rounds of the challenge, covering programming languages, software engineering, personal projects, and new technologies.

Rather than following a single curriculum or building one specific application, each round will have its own focus, objectives, and potentially a few additional challenges.

The bigger picture is to continuously improve as a developer through consistent practice, practical experience, and lifelong learning.

## My Rules

Based on the original [100 Days of Code rules](https://github.com/kallaway/100-days-of-code), with a few personal adjustments:

1. **Code every day.** Aim for at least one hour of focused programming.
2. **Build and learn.** Personal projects, coding exercises, coursework, testing, and meaningful refactoring all count.
3. **Document progress.** Record what I worked on, what I accomplished, and what I learned.
4. **Share the journey.** Post updates using `#100DaysOfCode` when possible.
5. **Keep moving forward.** Difficult days, mistakes, and unexpected challenges are part of the process.
6. **Stay flexible.** Each round may introduce new goals, technologies, or personal challenges.

Passive learning, such as watching tutorials or reading documentation, supports the challenge but doesn't replace hands-on coding.
