## The Neovim Challenge

<escape>**The twist:**</escape> Use **Neovim on Omarchy Linux** as my primary development environment for all 100 days.

I've used several development environments, but this round is an opportunity to develop greater proficiency and confidence working primarily within Neovim.

### My Neovim Rules

1. **Neovim First.** Start coding sessions in Neovim and use it as the default editor.
2. **Learn the Editor.** Improve my understanding of motions, text objects, registers, macros, and other Neovim features.
3. **Explore the Tooling.** Become more proficient with LSPs, formatting, linting, debugging, testing, and project navigation.
4. **Embrace the Terminal.** Make better use of terminal-based workflows and developer tools.
5. **Stay Practical.** Other IDEs and specialized applications are allowed when appropriate. Productivity and completing real work take priority over arbitrary restrictions.
6. **Document Discoveries.** Record useful Neovim tips, configurations, and workflow improvements along the way.

### The Goal

By Day 100, I want Neovim to feel like a natural, productive development environment rather than something I'm deliberately forcing myself to use.

**The goal is Neovim proficiency, not Neovim purity.**
